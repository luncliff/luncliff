# Retrospective

Keep the archive compact, cumulative, and reviewable, so it stays worth reading at the start of a later session. This repository keeps the notes under current workspace's `docs/` folder.

## Procedure

1. Read the existing notes first.
2. Update, merge, or compact an existing entry before adding a new one. Create a new file only when the takeaway fits no existing surface.
3. Write each takeaway in three parts:
   - Takeaway: the behavior to repeat or change.
   - Evidence: what happened in the session that supports it.
   - Apply when: the situation that should trigger it.
4. Organize entries by future behavior, not by job title or document type.
5. Prefer positive, composable rules over prohibitions.
6. Remove entries that later evidence contradicts, and say what changed.
